# Windows数据迁移助手 v1.0.0

把占空间的数据目录整棵搬到其他盘，并在原路径留下链接——程序继续照常按原路径访问。

> 搬走数据，留下链接。

## 这个工具解决什么问题

「C 盘满了」的常见解法是把某个数据目录剪切到别的盘，但**剪切之后原路径就没了**，
任何按原路径找数据的程序都会报错。

本工具在最后一步**把原路径做成链接**，所以两边都能继续用。典型场景：

- 软件的数据目录、缓存、素材库挪到容量盘，不改任何配置
- 游戏存档、Steam 库搬迁
- `node_modules`、模型缓存、SDK 这类「删了能重下、重下要几小时」的目录

## 迁移流程

```
检验 → 预扫描 → 复制 → 校验 → 源目录改名为备份 → 建立链接 → 确认后删除备份
```

**校验不通过绝不删除源目录；任何一步失败都可以回滚。**

## 这一版的几个关键设计

**迁移前必须检验。** 改名是唯一一个会等到最后才炸的错误——复制校验全过、用户等了几个小时，
才卡在改名上。检验里那次几毫秒的「试探改名」把这个风险提前暴露，红色错误会直接禁止下一步。

**占用进程可以交给工具处理。** 检验因改名被挡而失败时，会多出一个「找出占用进程」入口：
先缩小范围（只试探子目录——实测试探一个文件 0.67 毫秒，而让系统直接扫它只要 0.13 毫秒，
试文件永远是净亏），再问系统「谁占着」。

<details>
<summary>哪些进程工具<b>不会</b>关闭（点开看理由）</summary>

只要批次里混进一个受保护进程，工具就**一个都不关**——底层关闭接口是整批生效的，
放行就等于把 `explorer` 之类一起关掉。

| 类别 | 例子 | 理由 |
|---|---|---|
| 系统关键进程 | `System`、`smss`、`csrss`、`wininit`、`winlogon`、`services`、`lsass`、`svchost` | 关掉会蓝屏、重启、注销，或连带一批系统服务 |
| 桌面外壳 | `explorer.exe`、`dwm.exe` | 关掉会让桌面、任务栏和所有已打开的文件夹消失 |
| 安全软件 | `MsMpEng.exe`、`NisSrv.exe`、`SecurityHealthService.exe` | 关掉会让电脑失去实时防护 |
| 工具自己 | 本程序及其父进程链 | 关掉会把工具自己带走 |
| 身份不明 | 取不到可执行文件路径的进程 | 证明不了它是什么，就不能假设它安全 |

</details>

**它只碰你选的那两个目录。** 不读注册表、不联网、不收集任何信息。关闭进程走的是系统官方通道
（和安装程序让你「关闭以下程序以继续」同一个机制），程序会走正常退出流程、该提示保存的会提示保存。
**只有「强制结束」会丢未保存内容，而它需要单独确认。**

**回滚之后报告页会换成「恢复结果」。** 那件事已经被撤销了，继续顶着「迁移成功」是错的。

## 下载与运行

下载 `windows-data-migrator-1.0.0-win64.zip`，解压后双击里面的 `Windows数据迁移助手.exe`。

**绿色免安装**：不写注册表，删掉文件夹就是卸载。不需要管理员权限
（源树里有文件符号链接、或有读不了的目录时才需要，界面会提示）。

详细用法见压缩包里的 **`使用说明书.html`**，双击用浏览器打开。

## 系统要求

- Windows 10 / 11（64 位）
- 源与目标所在卷都需要支持 junction（NTFS 可以；FAT/exFAT 不行，工具会提前拦下来）

## 已知限制

| 限制 | 说明 |
|---|---|
| 目录句柄占用查不出进程 | 有程序把源目录本身当工作目录（资源管理器开着它、终端 `cd` 在里面）时，改名会被挡住，但系统接口拿不到那个进程。界面会如实说明并请你手动关 |
| 稀疏文件会变实占 | 稀疏文件（如动态 VHD）复制到目标端后会占用完整大小。计划页的空间需求按逻辑大小算，与之一致，不会中途才说空间不够 |
| 占用扫描在超大目录上耗时较长 | 成本约每文件 0.13 毫秒，进度条会显示进展 |
| 同盘迁移不释放空间 | 源与目标同卷时不会释放空间，且备份与原件同盘。工具会用黄色警告提示 |

## 关于杀毒软件误报

PyInstaller 打包、无数字签名的 exe，加上「遍历全盘 + 改名目录 + 建链接 + 关闭进程」这类行为，
**很可能被杀软误报**。

这个包没有数字签名（个人代码签名证书还在准备）。如果你遇到报毒：

- 源码在仓库里，可以核对该程序实际做了什么
- 也可以自行用 PyInstaller 从源码构建，构建脚本是 `packaging/build.ps1`
- 遇到具体误报欢迎开 issue 附上报毒截图与引擎名称
