# 品牌主图

`logo.png` 是界面品牌栏与 exe 图标的**唯一**图形来源（`dmig.ui.logo` 只负责缩放它）。

## 来源

模型：`qwen-image-2.1-pro`（dashscope），经 media-router 生成。**是图生图迭代出来的**，
一共三轮：

1. **文字生图**（本轮首次）
   *扁平矢量软件应用图标，深蓝到亮蓝渐变圆角方形瓷砖底，正中一个白色文件夹，
   文件夹右上角伸出一支向右的白色粗箭头表示数据搬移出去，几何造型大胆简洁，
   无任何文字，居中构图，高对比度，微软 Fluent Design 风格，边缘干净，
   适合做 Windows 桌面软件图标*
2. **图生图**：以第 1 步为参考，让文件夹更大、飞出的数据块更粗更少
3. **图生图**（当前采用）：以第 2 步为参考，改等距立体视角

1024×1024，无文字（图标不该带字，AI 出字也必糊）。

## 瓷砖自带的立体描边

左边缘有一条约 8px 的浅蓝竖带（`(97,144,228)`，而内侧是 `(21,90,203)`），
四角同样有。**这是原图的凸起描边，不是抠图的毛边**——抠图逐像素忠实于原图，
放大源图边缘即可确认。深色背景下比浅色下明显一些。

要平坦边缘的话，把饱和度阈值从 80 提到 140 就能把这条描边切掉（描边饱和度
125~131，瓷砖本体 174~184）。

## 白边是怎么来的（改这张图时最容易踩的坑）

AI 出的是**「蓝瓷砖 + 白底 + 一圈柔光」**，直接用会导致两个问题：

1. **白底不透明** —— 任务栏是深色，图标会显示成一个白方块。必须抠。
   不能简单地「白色变透明」：文件夹也是白的，那会把文件夹戳出洞。
   做法是**逐行取蓝色像素的最左/最右并填满**求轮廓——瓷砖是凸的，这样得到
   的形状完全跟着原图走（AI 出的其实是 iOS 那种超椭圆，拿圆角矩形去套，
   四个角弧度对不上，会露出底下的柔光）。
2. **透明区的 RGB 还是白的** —— 这是最隐蔽的一条。抠完之后 alpha=0 的像素
   RGB 仍是 (247,248,251)，而缩放（Lanczos、Qt 的 SmoothTransformation 都是
   按**非预乘** alpha 插值）会把这点白混进边缘像素，深色底下就是一圈洗不掉的
   浅色毛边。**必须把 alpha 极低处的 RGB 也染成边缘蓝**，混出来才还是蓝的。

第 2 条不修的话，1024 下看不出来，16/32 下最明显——而那正是任务栏的尺寸。
